# Weather Telegram Bot

Простой и удобный Telegram-бот для получения актуальной погоды в любом городе мира. Работает через публичный API погоды, отвечает на команды пользователя и показывает температуру, влажность и другие параметры.

## Возможности

- Получение погоды по названию города
- Кнопки быстрого ответа с популярными городами: Москва, Санкт-Петербург
- Понятное форматирование ответа: температура, ощущается как, влажность, ветер
- Обработка ошибок: если город не найден, бот сообщает об этом
- Защита от слишком частых запросов

### Команды

- `/start` — приветственное сообщение и инструкция
- `/help` — список доступных команд

## Технологии

- Python 3
- pyTelegramBotAPI (telebot) для работы с Telegram Bot API
- Requests для запросов к API погоды
- OpenWeatherMap API как источник данных
- python-dotenv для хранения токенов в переменных окружения

## Запуск

1. Склонируйте репозиторий:
   git clone https://github.com/azatikson/simple-weather-telegram-bot.git

2. Установите зависимости:
   pip install -r requirements.txt

3. Создайте файл `.env` в корне проекта и добавьте свои ключи:
   TELEGRAM_BOT_TOKEN=ваш_токен_бота
   WEATHER_API_KEY=ваш_ключ_openweathermap

4. Запустите бота.
  
## Зачем этот проект

Погода это один из самых частых запросов в повседневной жизни. Открывать приложение, смотреть рекламу, пролистывать блоки с новостями и гороскопами ради одной цифры температуры — неудобно. Telegram уже открыт у большинства людей, поэтому логично получать погоду прямо в нём.

Бот решает одну задачу: за 2 секунды получить актуальную погоду в нужном городе без лишних действий.

## Продуктовые решения

Почему именно такой набор фич и такой интерфейс:

- **Бот в Telegram, а не отдельное приложение.** Установка приложения ради погоды это лишний барьер. Telegram уже установлен у 900+ млн человек, а бот не требует ничего скачивать
- **Кнопки быстрого ответа для популярных городов.** Большинство запросов это Москва и Санкт-Петербург. Кнопки экономят ввод и снижают трение. Это классический приём из продуктовой разработки: сделать частый сценарий в один тап
- **Команды /start и /help.** Новичок, который впервые открыл бота, должен понять за 5 секунд, что делать. /start объясняет базовый сценарий, /help напоминает список команд
- **Понятное форматирование ответа.** Цифры без подписей читаются плохо. Бот показывает не только температуру, но и ощущаемую температуру, влажность и ветер. Это то, что реально влияет на решение «что надеть»
- **Обработка ошибок с человеческим текстом.** Если город не найден, бот не падает и не показывает стек ошибки. Он объясняет проблему простым языком и подсказывает, что делать
- **Защита от частых запросов.** Пользователь может случайно отправить 5 сообщений подряд. Без защиты это 5 запросов к API. Простое ограничение по времени экономит квоту и защищает от блокировки со стороны OpenWeatherMap

## Метрики продукта

Как я оценивал бы успех этого бота, если бы развивал его как продукт:

- **DAU и WAU.** Сколько уникальных пользователей обращаются к боту ежедневно и еженедельно
- **Retention D7 и D30.** Возвращаются ли пользователи к боту через неделю и месяц. Для погоды это ключевая метрика: если не возвращаются, значит, сценарий неудобен
- **Среднее число запросов на пользователя в день.** Показывает, насколько бот встроился в привычку
- **Доля успешных запросов.** Сколько запросов завершились корректным ответом, а сколько упали в ошибку (город не найден, API недоступен)
- **Использование кнопок быстрого ответа.** Если кнопки популярных городов используются чаще, чем ручной ввод, значит, сценарий работает
- **Время ответа.** Погода должна приходить за 1–2 секунды. Если дольше, пользователь уйдёт

## Планы по развитию

- Геолокация: определять город пользователя автоматически
- Прогноз на 3 и 7 дней
- Уведомления по расписанию: например, каждое утро присылать погоду в сохранённом городе
- Сохранение любимых городов пользователя
- Переключение единиц измерения (Цельсий и Фаренгейт)
- Погодные предупреждения: дождь, снег, сильный ветер
- Inline-режим: получать погоду прямо в чате, не открывая бота
